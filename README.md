## 📌 Technical Overview

**Product Discount Calculator** is an object-oriented backend utility written in modern PHP. It processes product list prices, evaluates tiered percentage/flat discounts, calculates applicable sales tax, and formats output with input sanitization.

---

## ✨ Key Features

- **Robust Discount Evaluation**: Evaluates percentage, fixed-rate, and tiered volume discount logic.
- **Input Sanitization & Validation**: Defense against malformed numeric inputs and edge-case negative balances.
- **Clean Object-Oriented Design**: Encapsulates pricing models and business logic into maintainable PHP classes.
